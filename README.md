# PoE Overlay (XenonTrade restoration)

Work-in-progress restoration of [XenonTrade](https://github.com/klayveR/xenontrade) for Path of Exile 1 on Arch Linux / Manjaro X11.

Original source: Tobias Hoffmann / klayveR, MIT license. This fork is not yet a tested production build. Modern poe.ninja API adapter and migration work are in progress.

See `RESTORATION.md` for technical status and outstanding tasks.
